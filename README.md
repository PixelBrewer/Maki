# Maki

Maki is a small CLI tool for bootstrapping modern C++ projects on macOS and Linux.

It was created to make starting a terminal-first C++ project feel closer to tools such as Angular's `ng new`: choose a project name, generate a sensible starting structure, and then continue using the standard C++ toolchain directly.

Maki does **not** replace CMake, Ninja, Clang, or Git. It simply creates the project structure and configuration needed to get started quickly.

## Features

Maki supports:

- Creating a new C++ project with `maki new <name>`
- Project name validation
- Dry-run previews without writing files
- Optional Git repository initialization
- CMake project generation
- CMake presets configured for Clang and Ninja
- C++23 by default
- Debug build preset
- `compile_commands.json` generation for tools such as `clangd`
- macOS and Linux

## Generated Project

Running:

```bash
maki new MyProject
```

creates:

```text
MyProject/
├── .gitignore
├── CMakeLists.txt
├── CMakePresets.json
├── include/
└── src/
    └── main.cpp
```

The generated project uses:

- Clang / Clang++
- CMake
- Ninja
- C++23

The generated `CMakePresets.json` includes a `debug` preset and enables `CMAKE_EXPORT_COMPILE_COMMANDS`.

## Installation

Prebuilt self-contained binaries are available from the [GitHub Releases](https://github.com/PixelBrewer/Maki/releases) page.

Release builds are available for:

- Linux x64
- macOS Apple Silicon
- macOS Intel

Because Maki is published as a self-contained .NET application, the .NET runtime or SDK is **not required** to use a release build.

### Linux

Download the `linux-x64` archive from the [latest GitHub release](https://github.com/PixelBrewer/Maki/releases/latest).

For example, for `v0.1.0`:

```bash
tar -xzf maki-v0.1.0-linux-x64.tar.gz
```

Move the executable somewhere on your `PATH`:

```bash
sudo mv maki /usr/local/bin/maki
```

Verify the installation:

```bash
maki --help
```

### macOS — Apple Silicon

For Apple Silicon Macs, download the `osx-arm64` archive from the [latest GitHub release](https://github.com/PixelBrewer/Maki/releases/latest).

For example, for `v0.1.0`:

### macOS Gatekeeper

Maki is not currently notarized with Apple. macOS may therefore prevent a downloaded release from opening.

If macOS reports that it cannot verify Maki, remove the quarantine attribute from the extracted executable:

```bash
xattr -d com.apple.quarantine maki
```

Then move it onto your `PATH`:

```bash
sudo mv maki /usr/local/bin/maki
```

and verify:

```bash
maki --help
```

## Prerequisites

Maki itself does not require the .NET SDK when installed from a release.

The C++ projects generated by Maki expect the following tools to be available on your `PATH`:

- Clang
- CMake
- Ninja

Git is optional and is only required when using the `--git` option.

### Arch Linux

```bash
sudo pacman -S clang cmake ninja git
```

Git can be omitted if you do not intend to use `--git`.

### macOS

Using Homebrew:

```bash
brew install llvm cmake ninja
```

Git is available through the Xcode Command Line Tools and can also be installed through Homebrew.

Make sure `clang`, `clang++`, `cmake`, and `ninja` are available on your `PATH` before configuring a generated project.

## Usage

Create a new project:

```bash
maki new MyProject
```

Maki will generate the project and display the commands needed to configure and build it.

### Dry Run

Preview the project without writing anything to disk:

```bash
maki new MyProject --dry-run
```
